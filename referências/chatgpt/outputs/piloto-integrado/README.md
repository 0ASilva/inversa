# Piloto integrado E1–E6 · v0.33

Abrir index.html ou ../piloto-completo-ate-e6.html. E1 é provisória; E7/E8 não integram o piloto. A etapa usa todo o quadro: o cabeçalho comum está dentro de cada atividade. Não existe botão Continuar no topo. Menu de etapas permite acesso livre, sem registrar conclusão. Rodapé interno conduz o percurso respeitando suas liberações.

As atividades são carregadas sob demanda e conservadas em memória em iframes. Mensagens entre quadros têm remetente conferido. Som é compartilhado em memória; recarregar apaga respostas e preferências. Não há login, envio, armazenamento persistente ou publicação.

Recompilar todos os módulos pelo script ../manutencao/recompilar-pilotos.py. build.py compila somente a casca usando etapas/ já atualizadas. Ver ../layout-geral/README.md para manutenção dos controles e ícones.
