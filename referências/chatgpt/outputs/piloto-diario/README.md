# E6 — Diário de descobertas

Piloto com retomadas de E2–E5. Cada experiência tem três momentos: recordar uma relação matemática com apoio visual opcional; indicar percepção de aprendizagem; escrever uma reflexão ou optar pela explicação oral. Navegação livre; nenhuma resposta bloqueia avanço. Som e celebração nos acertos matemáticos, sem classificar autoavaliação como certa/errada.

Respostas apenas em memória; nada gravado, enviado ou persistido. Resumo temporário ao final, sem nota ou ranking. Não captura áudio. A explicação geométrica do proponente existe em HTML local, ainda não recebido; não está incorporada. O desenho de reflexão é apenas retomada, não substitui essa explicação.

Preservada distinção: E3 usa +3 e E5 +4. Revisar com o proponente se deseja uniformizar posteriormente. Sintaxe JavaScript verificada; experiência em celulares reais, teclado virtual e tecnologias assistivas ainda requer validação. Piloto não publicado.

## v0.25 — leitura e visualização

Interface inspecionada no navegador; dispositivos reais ainda requerem teste.
